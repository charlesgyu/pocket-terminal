# Security · 보안

## Reporting a vulnerability · 취약점 신고

Please do not open a public issue for security problems.
Email **bavoya@gmail.com** with the details. You will get a reply as soon as possible.

보안 문제는 공개 이슈로 올리지 말고 **bavoya@gmail.com** 으로 알려 주세요.

## Official source · 공식 설치 경로

The only official source of this plugin is `github.com/charlesgyu/pocket-terminal`.
Copies (forks) elsewhere are not maintained or checked by the author. Install only from here.

이 플러그인의 공식 경로는 `github.com/charlesgyu/pocket-terminal` 하나뿐입니다. 다른 곳의 복사본은 작성자가 관리하거나 확인하지 않으니, 여기서만 설치하세요.

All commits on `main` are signed by the author. 이 저장소의 모든 커밋은 작성자의 서명이 있습니다.
